## Project
Build a personal About-Me website using React and Vite, hosted on GitHub Pages.

## Commands
- npm install
- npm run dev
- npm run build

## Rules
- Store personal content in src/profile.js.
- Never invent facts about me.
- Use plain React and CSS.
- Make the website responsive and accessible.
- Never commit passwords, API keys, node_modules, or dist.

## Git Workflow
- Show every Git command before running it.
- Make small commits with clear messages.
- Never force-push or rewrite Git history.
